# brain.com.ua Scraper

Web scraping project that collects product data from brain.com.ua
using several approaches.

## Tech stack
- Python
- Requests + BeautifulSoup4
- XPath (lxml)
- Selenium

## What it does
- Collects product information (name, price, specs, etc.)
- Handles pagination and dynamic content (Selenium)
- Saves structured data (CSV / JSON / database)

## How to run
pip install -r requirements.txt
python main.py
